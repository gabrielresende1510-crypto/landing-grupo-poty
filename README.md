# Landing do Grupo Poty

Página do grupopoty.com.br, para clínicas. HTML, CSS e JavaScript puros, sem build.

- `index.html`: a página principal.
- `privacidade.html`: a página de privacidade.
- `js/config.js`: o número do WhatsApp, o código do Google Analytics (vazio = sem medição) e as chaves das versões do texto.

Para publicar, coloque todos os arquivos na raiz da hospedagem, como estão aqui.
